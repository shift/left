# Credits & Sources

> 📍 Sprint 1 · 1 decisions made

**Shift-Left** is a satirical text adventure about the chaos of software engineering. Every incident is based on a real event.

**Incidents referenced in this game:**

*📖 Knight Capital (2012)* — $440M lost in 45 minutes. Wrong deployment target reactivated old code on one server out of eight.

*📖 GitLab (2017)* — Production database deleted. 6 hours of data lost. Five backup mechanisms, all failing silently.

*📖 Equifax (2017)* — 147M SSNs leaked. Known CVE left unpatched for 2 months. CTO and CISO resigned.

*📖 CrowdStrike (2024)* — 8.5M Windows machines crashed after a bad content update. Airlines, hospitals, banks grounded.

*📖 TSB Bank (2018)* — Migration broke for 1.9M customers. CEO resigned. Cost £330M.

*📖 Southwest Airlines (2022)* — 16,700 flights canceled over Christmas. Legacy crew system failed under load. $1.2B cost.

*📖 Capital One (2019)* — SSRF vulnerability exposed 100M records. $190M settlement.

*📖 SolarWinds (2020)* — Supply chain attack via compromised build pipeline. 18,000 customers affected. Foreign intelligenceoperatives inside.

*📖 Maersk/NotPetya (2017)* — Malware spread through network with no air-gapping. $300M in losses. Entire shipping disrupted globally.

*📖 Healthcare.gov (2013)* — Political deadline overrode engineering readiness. 6 people enrolled on day one.

*📖 British Airways (2019)* — Single line of JS redirected 380,000 payment forms to hacker server. £183M fine.

*📖 Uber (2016)* — Breach covered up for a year. $100K bug bounty paid to hackers. CTO charged with obstruction.

*📖 left-pad npm (2016)* — 11 lines unpublished, half the internet broke. Including yours probably.

**Tech debt themes** inspired by: the myth of "we'll fix it later," the velocity trap, the sprint velocity lie, the myth of the 10x engineer, and the eternal Friday deploy.

**Why this exists:** Because every developer has lived this. This is the joke we tell each other in post-mortems.
