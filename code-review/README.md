# The Review

> 📍 Late Game · 6 decisions made

A junior developer submits a PR. 2,000 lines. The description says "fixes stuff." No tests. Variable names are single letters. There's a `// TODO: fix this later` in a function called `doThings()`.

You could approve quickly. Or you could be the reviewer you wish you'd had.

*The Linux kernel has a rule: every patch is reviewed by at least one other developer. It's one of the largest software projects in history and it has fewer bugs per thousand lines than most corporate codebases. Review is not optional. Review is the product.*
