# How to Play

> 📍 Sprint 1 · 1 decisions made

🎮 *Welcome to Shift-Left.*

This is a text adventure played entirely through GitHub README files. No app to download, no account to create, no JavaScript required.

**How it works:**
- You are a developer at a startup. Your goal: reach Production without getting fired.
- Read each room's scenario. Pick a choice by clicking a link.
- Each choice commits you to a path. There is no going back.
- Some paths lead to success. Most lead to incidents.
- All the incidents in this game are based on real events.

**The four repos are four acts:**
- **shift/left** — The Dev Dungeon. Sprints, PRs, tech debt.
- **shift/up** — The Cloud. AWS, architecture decisions, bills.
- **shift/down** — The Basement. On-call, incidents, legacy servers.
- **shift/right** — Production. The final exam.

**Tips:**
- The progress bar ("Sprint 2 · 3 decisions made") tells you how deep you are.
- Strike warnings are subtle. Pay attention to the prose.
- Read the *📖 footnotes*. They reference real incidents.
- Multiple paths exist. Try different choices.

**Estimated time:** 45-90 minutes.

Good luck. You'll need it.
