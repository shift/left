# The Estimate

Planning poker. The feature is "Integrate with third-party payment provider." You've never integrated a payment provider before.

The junior says 2 days. The senior says 3 weeks. Everyone looks at you.

*McConnell's "Software Estimation" rule: the accuracy of an estimate is proportional to how well you understand the problem. If you've never done it before, your estimate is a guess. The industry average for project overrun is 2.5x. Not 10% over. 150% over.*
